# Chainlit Cookbook Explorer

Интерактивный статический каталог официального [Chainlit Cookbook](https://github.com/Chainlit/cookbook).

## Открыть

Откройте `index.html` двойным кликом. Сервер, сборка и API-ключи не нужны. Исходники рецептов встроены в `data.js`. Интернет используется только для необязательного шрифта и переходов по внешним ссылкам.

Альтернативно из этой папки:

```sh
python3 -m http.server 8080
```

Затем откройте http://localhost:8080.

## Возможности

- Категории, поиск, фильтры технологий, сортировка.
- Избранное в localStorage (если браузер разрешает).
- Архивные рецепты — переключатель «Включить архив».
- Локальные интерактивные UI-эскизы: чат с потоковой печатью, подтверждения, график, схематичная карта, выбор файла.
- Оригинальный код, README и ссылка на каждый рецепт; прямые ссылки через URL-фрагмент.
- Адаптивная вёрстка, клавиатурная навигация, `/` для поиска, Escape для закрытия.

**Демо не запускают Python, модели или инструменты.** Это иллюстрации типов сценариев, а не точные копии всех оригинальных приложений. Ответы фиксированные, файл не читается и не отправляется, графики и карты используют тестовые данные. Для настоящего запуска следуйте README соответствующего рецепта. Некоторые рецепты требуют платных сервисов; архивные могут быть устаревшими.

## Файлы

- `index.html`, `style.css`, `app.js` — интерфейс.
- `tree.json` — снимок дерева upstream.
- `data.js`, `build_data.py` — локальные данные и генератор.
- `tests/` — браузерные проверки.

Для проверки: `npm install && npm test`. По умолчанию используется установленный Google Chrome на macOS; путь можно изменить в `playwright.config.js`.

Для повторной загрузки файлов закреплённого снимка: `python3 build_data.py`. Для перехода на новый upstream сначала обновите `tree.json` через GitHub Trees API; описания в генераторе курируются отдельно.

Контент рецептов принадлежит авторам Chainlit Cookbook; ссылки ведут к оригинальным материалам. Каталог не является официальным продуктом Chainlit.
